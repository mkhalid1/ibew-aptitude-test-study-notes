# Glossary

Terms you will meet in the application process, on the test and in these notes.

| Term | Meaning |
|---|---|
| **Algebra and Functions** | The first test in the battery: 33 items in 46 minutes. |
| **Battery** | A set of tests taken together. The NJATC aptitude test battery has two tests. |
| **Coefficient** | The number in front of a letter. In 3x, the coefficient is 3. |
| **Difference of squares** | An expression of the form p² − q², which factors as (p − q)(p + q). |
| **Direct variation** | A relationship y = kx, where y doubles when x doubles. |
| **Eligibility list** | The ranked list of applicants who passed the interview stage. Names stay on it for two years. |
| **electrical training ALLIANCE** | The joint training organization of NECA and the IBEW, previously called the NJATC. It develops the aptitude test battery. |
| **Expand** | Multiply out brackets. |
| **Factor** | Write an expression as a product of brackets. The reverse of expanding. |
| **Function** | A rule that gives one output for each input, often written f(x). |
| **IBEW** | International Brotherhood of Electrical Workers. |
| **Inequality** | A statement using <, >, ≤ or ≥. Its solution is usually a range of values. |
| **Inside Wireman** | An apprenticeship classification for commercial and industrial electrical work. Some programs set a different qualifying score for it. |
| **Interleaved pattern** | A number pattern made of two simpler patterns that take turns. |
| **Inverse variation** | A relationship y = k ÷ x, where y halves when x doubles. |
| **JATC** | Joint apprenticeship and training committee: the local body, with NECA and IBEW members, that runs an apprenticeship program. |
| **Like terms** | Terms with the same letters and powers, which can be added together, such as 6a and −2a. |
| **NECA** | National Electrical Contractors Association. |
| **NJATC** | The former name of the electrical training ALLIANCE. The test battery still carries the name. |
| **Oral interview** | The step after a qualifying test score, with a committee representing NECA and the IBEW. |
| **Qualifying score** | The minimum result a program needs to invite you to interview. Set by each program. |
| **Reading Comprehension** | The second test in the battery: 36 items in 51 minutes. |
| **Slope** | How steep a line is: change in y divided by change in x. |
| **Stanine** | A standard nine-point scale, 1 to 9, with 5 in the middle. Some programs report the test on a 1 to 9 scale. |
| **Substitute** | Replace a letter with a number. |
