# Functions, tables and inequalities

**In one line:** you read a rule that links x to y, find it from a table, check which points fit it, and solve inequalities.

This is the "functions" half of the **Algebra and Functions** test. The official sample page has an item that asks which statement about a formula is true for a range of values, and another that asks which rule matches a table. This page covers both, plus the related skills you need to answer them quickly.

## What it measures

Whether you understand a formula as a relationship, not just a calculation:

- what y does as x gets bigger or smaller
- which rule produces a given table of values
- which points lie on a line
- for which values of x a statement is true (an inequality)
- direct and inverse proportion: when one quantity doubles, what happens to the other

## How the questions look

A function, a table or an inequality, then four choices labelled A to D. Typical stems, in our own words:

| Type | Typical stem |
|---|---|
| Evaluate a function | "If f(x) = 2x² − 5, what is f(3)?" |
| Rule from a table | "Which rule gives the values in this table?" |
| Solve an inequality | "Which values of x make 7 − 2x > 1 true?" |
| Point on a line | "Which point lies on y = 2x − 7?" |
| Slope | "A line passes through (1, 1) and (3, 7). What is its slope?" |
| Proportion | "y varies directly with x. If y = 18 when x = 6, what is y when x = 10?" |

## A method that works

1. **For f(x) items,** treat f(3) as "put 3 wherever you see x." It is substitution with different notation.
2. **For tables,** look at how y changes when x goes up by 1. That change is the number in front of x. Then find the constant by putting one pair from the table into y = (change)x + c.
3. **Test every row.** A rule that fits the first row can fail the second. Before you pick, check at least two rows, ideally the first and last.
4. **For inequalities,** solve exactly as you would an equation, with one extra rule: if you multiply or divide both sides by a negative number, flip the sign. Then test one value from your answer in the original.
5. **For points on a line,** substitute the x value and see whether you get the y value. Stop at the first match, but make sure it really matches.
6. **For slope,** use (change in y) ÷ (change in x), subtracting in the same order on top and bottom.

## Traps that cost points

- **Forgetting to flip the inequality.** −2x > −6 becomes x < 3, not x > 3. This is the most common wrong answer on inequality items.
- **Fitting one row only.** y = x + 4 fits the first row of a table that starts (1, 5), but not the rest.
- **Mixing up x and y in a point.** (3, 1) means x = 3 and y = 1. Always x first.
- **Slope upside down.** Change in y goes on top. Dividing change in x by change in y gives the reciprocal.
- **Assuming "increase" always means "bigger y".** In y = 12 − 3x, y gets smaller as x grows. Read the sign in front of x.
- **Counting integers in a range.** −2 < x < 4 does not include −2 or 4. List the whole numbers to be sure.

## Timing

Table and inequality items take 45 to 90 seconds with the row check. Statement items ("which of the following is true") can take longer, because you may need to test several choices. Test the choice that looks most likely first, and stop as soon as one is clearly true.

## Practice items

These 5 items are original, written for these notes. They are not taken from the NJATC aptitude test or any publisher's materials.

**Item 1.** If f(x) = 2x² − 5, what is f(3)?

A. 1 · B. 13 · C. 31 · D. 7

**Item 2.** Which rule gives the values in this table?

| x | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| y | 5 | 8 | 11 | 14 |

A. y = 3x + 2 · B. y = x + 4 · C. y = 2x + 3 · D. y = 5x

**Item 3.** Which values of x make 7 − 2x > 1 true?

A. x < −3 · B. x > −3 · C. x > 3 · D. x < 3

**Item 4.** A straight line passes through the points (1, 1) and (3, 7). What is its slope?

A. 6 · B. 2 · C. 4 · D. 3

**Item 5.** y varies directly with x. If y = 18 when x = 6, what is y when x = 10?

A. 22 · B. 33 · C. 30 · D. 60

<details>
<summary>Answers and explanations, items 1 to 5</summary>

**Item 1: B (13).** Square first: 3² = 9. Then 2 × 9 = 18, and 18 − 5 = 13. *Why not C:* 31 is (2 × 3)² − 5, which doubles before squaring.

**Item 2: A (y = 3x + 2).** When x goes up by 1, y goes up by 3, so the rule starts y = 3x. For x = 1, 3 × 1 = 3, and y is 5, so add 2. Check the last row: 3 × 4 + 2 = 14. *Why not B:* y = x + 4 fits x = 1 (5) but gives 6 for x = 2, not 8. *Why not C:* y = 2x + 3 fits x = 1 but gives 7 for x = 2.

**Item 3: D (x < 3).** Subtract 7: −2x > −6. Divide by −2 and flip the sign: x < 3. Test x = 0: 7 − 0 = 7, which is greater than 1. True. *Why not C:* x > 3 forgets to flip. Test x = 4: 7 − 8 = −1, which is not greater than 1.

**Item 4: D (3).** Change in y: 7 − 1 = 6. Change in x: 3 − 1 = 2. Slope = 6 ÷ 2 = 3. *Why not A:* 6 is the change in y alone. *Why not B:* 2 is the change in x alone.

**Item 5: C (30).** Direct variation means y = kx. 18 = k × 6, so k = 3. Then y = 3 × 10 = 30. *Why not A:* 22 adds 4 to 18 because x went up by 4. That is an add pattern, not a direct proportion.

</details>
